# AraNotch 0.13.0

- Thông báo agent thả xuống từ notch: khi Claude Code hoặc Codex bắt đầu làm một yêu cầu, khi nó cần bạn, và khi nó làm xong, một thẻ hẹp thả xuống dưới notch trong vài giây rồi tự thu lại.
- Ước lượng mức dùng: khi agent có báo giới hạn 5 giờ, thẻ "Đang làm" cho biết lượt này ước tốn bao nhiêu, hiện còn bao nhiêu và dự kiến còn bao nhiêu; thẻ "Đã xong" cho biết lượt vừa rồi đã tốn bao nhiêu.
- Cài đặt › Agents có thêm công tắc "Báo khi agent bắt đầu làm".

---

- Agent notices drop out of the notch: when Claude Code or Codex starts on a request, when it needs you and when it is done, a narrow card drops under the notch for a few seconds.
- A usage estimate: when the agent reports its 5-hour limit, the "Working" card says about how much the turn will take, what is left now and what is expected to be left; the "Done" card says what the turn took.
- Settings › Agents has a new switch, "Tell me when an agent starts working".
