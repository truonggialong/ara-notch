# Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Một bộ đếm ngược trên notch, hiện thời gian còn lại khi notch đóng và báo khi hết giờ.

**Architecture:** `TimerCore` giữ máy trạng thái đếm ngược, định dạng và cài đặt dưới dạng kiểu thuần. `TimerFeature` thêm một trang notch, một bộ hẹn giờ 1 Hz và các hoạt động trực tiếp.

**Tech Stack:** Swift 6, SwiftUI, AppKit (`NSSound`), Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-11-timer-design.md`

## Global Constraints

- `TimerCore` chỉ import Foundation. Không dùng macro SwiftUI.
- Hằng số từ spec: thời lượng 1 giây đến 3 giờ; số phút 1…180, mặc định 25; mức sẵn 5, 15, 25, 45; hoạt động khi đếm ưu tiên 1, khi hết giờ ưu tiên 3 trong 6 giây.
- Chuỗi hiển thị có đủ `en` và `vi`. Chạy test bằng `Scripts/test.sh`. Mỗi task kết thúc bằng một commit.

## Review Focus

1. **`tick` gọi muộn hoặc gọi lặp:** chỉ một lần trả về đúng. Test ở Task 1.
2. **Tạm dừng rồi tiếp tục nhiều lần:** tổng thời gian đếm không đổi. Test ở Task 1.
3. **Thao tác sai trạng thái:** `pause` khi rảnh, `resume` khi đang đếm, `cancel` khi rảnh không làm gì. Test ở Task 1.
4. **Thời lượng ngoài khoảng:** 0, âm, rất lớn. Test ở Task 1.
5. **Làm tròn hiển thị:** 59,2 giây hiện `1:00`, không phải `0:59`. Test ở Task 1.

### Task 1: `TimerCore`

**Files:** Modify `Package.swift`; Create `Sources/TimerCore/CountdownTimer.swift`, `TimerFormat.swift`, `TimerSettingsStore.swift`; Test `Tests/TimerCoreTests/*.swift`

**Interfaces — Produces:**

```swift
public struct CountdownTimer: Equatable, Sendable {
    public enum Phase: Equatable, Sendable { case idle, running(endsAt: Date), paused(remaining: TimeInterval), finished }
    public static let durationRange: ClosedRange<TimeInterval> = 1...10_800
    public private(set) var phase: Phase
    public private(set) var duration: TimeInterval
    public init()
    public mutating func start(duration: TimeInterval, at now: Date)
    public mutating func pause(at now: Date)
    public mutating func resume(at now: Date)
    public mutating func cancel()
    public mutating func tick(at now: Date) -> Bool
    public func remaining(at now: Date) -> TimeInterval
    public func progress(at now: Date) -> Double
}
public enum TimerFormat { public static func clock(_ seconds: TimeInterval) -> String }
public struct TimerSettingsStore {
    public static let minutesRange: ClosedRange<Int> = 1...180
    public static let presets = [5, 15, 25, 45]
    public init(defaults: UserDefaults)
    public var minutes: Int { get nonmutating set }
    public var soundEnabled: Bool { get nonmutating set }
}
```
