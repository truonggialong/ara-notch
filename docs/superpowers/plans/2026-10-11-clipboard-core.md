# Clipboard Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lưu mọi thứ người dùng sao chép và hiện thành hàng thẻ trên notch; bấm thẻ để dán lại.

**Architecture:** `ClipboardCore` giữ mô hình, phân loại, truy vấn, quy tắc riêng tư, kho SQLite và cài đặt, tất cả kiểm thử được mà không cần clipboard hệ thống. `ClipboardFeature` nối `NSPasteboard`, phím dán và SwiftUI vào lõi đó, rồi cung cấp một trang cho `NotchController`.

**Tech Stack:** Swift 6, SQLite3 của hệ thống (không thư viện ngoài), CryptoKit, AppKit, SwiftUI, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-11-clipboard-core-design.md`

## Global Constraints

- `ClipboardCore` chỉ import Foundation, SQLite3, CryptoKit. Không AppKit, không SwiftUI.
- Không thêm phụ thuộc ngoài vào `Package.swift`.
- Giới hạn từ spec: văn bản tối đa 1 000 000 byte; ảnh tối đa 20 000 000 byte; `maxItems` mặc định 500 trong khoảng 50…1000; chu kỳ theo dõi clipboard 0,5 giây; chờ 0,08 giây trước khi gửi ⌘V.
- Kiểu clipboard riêng tư: `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword`.
- Lược đồ SQLite phiên bản 1, lưu trong `PRAGMA user_version`.
- Chuỗi hiển thị có đủ `en` và `vi` trong `Resources/*.lproj/Localizable.strings`.
- Chạy test bằng `Scripts/test.sh`. Test không được ghi vào `~/Library`; kho dùng thư mục tạm, cài đặt dùng `InMemoryDefaults`.
- Mỗi task kết thúc bằng một commit.

## Review Focus

1. **Văn bản chỉ có khoảng trắng hoặc xuống dòng:** không được tạo mục. Test ở Task 3.
2. **Ký tự đặc biệt trong nội dung:** dấu nháy đơn, `%`, emoji và tiếng Việt phải lưu và đọc lại nguyên vẹn. Test ở Task 3.
3. **Chuỗi trông giống màu hoặc liên kết nhưng không phải:** `#hello`, `rgb(300, 0, 0)`, `http://`, `https://a.com và thêm chữ` phải là văn bản thường. Test ở Task 1.
4. **Bộ lọc viết hoa và tên app có dấu:** `@IMAGE` và `@zalo` khớp "Zalo", `duong` khớp "Đường". Test ở Task 2.
5. **Ảnh bị cắt bỏ rồi sao chép lại:** sau khi mục ảnh bị xoá do vượt giới hạn, thêm lại đúng ảnh đó phải tạo lại tệp trong `blobs/`. Test ở Task 3.

public enum ClipboardStoreError: Error, Equatable {
    case cannotOpen(String)
    case unsupportedSchema(version: Int)

}
public final class ClipboardStore {
    public static let schemaVersion = 1
    public static let maxTextBytes = 1_000_000

Chuỗi được bind với `SQLITE_TRANSIENT`.

| `emptyFileListIsRejected` | `.files([])` trả `nil` |

| `deleteRemovesItemAndBlob` | xoá mục ảnh thì `items()` rỗng và tệp trong `blobs/` biến mất |
| `deleteAllRemovesEverything` | sau `deleteAll()` thì `items()` rỗng và `blobs/` không còn tệp |
| `pruneKeepsNewestUpToMaxItems` | `maxItems: 3`, thêm 5 mục: còn 3 mục mới nhất |
| `pruneRemovesBlobs` | `maxItems: 1`, thêm ảnh rồi thêm văn bản: tệp ảnh biến mất |
| `loweringMaxItemsPrunesImmediately` | thêm 5 mục rồi `setMaxItems(2)`: còn 2 |
| `prunedImageCanBeAddedAgain` (Review Focus 5) | `maxItems: 1`, thêm ảnh, thêm văn bản, thêm lại đúng ảnh đó: mục ảnh tồn tại và `imageData(for:)` trả đúng dữ liệu |
