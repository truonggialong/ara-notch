# Boards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ghim mục clipboard vào các board có tên; mục đã ghim sống sót qua việc cắt bớt và xoá lịch sử.

**Architecture:** Board và liên kết ghim là hai bảng mới trong kho SQLite (lược đồ 4), mọi quy tắc nằm trong `ClipboardStore`. `ClipboardFeature` thêm hàng chip, hàng soạn board và mục menu ghim trên trang notch.

**Tech Stack:** Swift 6, SQLite3, SwiftUI, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-11-boards-design.md`

## Global Constraints

- Giới hạn từ spec: 20 board; 200 mục mỗi board; tên board tối đa 40 ký tự; lược đồ phiên bản 4.
- `ClipboardCore` không import AppKit hay SwiftUI. Không dùng macro SwiftUI.
- Mục đã ghim không bao giờ bị cắt bớt hay bị `deleteAll()` xoá.
- Chuỗi hiển thị có đủ `en` và `vi`. Chạy test bằng `Scripts/test.sh`. Mỗi task kết thúc bằng một commit.

## Review Focus

1. **Xoá lịch sử khi có mục ghim là ảnh:** tệp ảnh của mục đã ghim phải còn; tệp của mục chưa ghim phải mất. Test ở Task 1.
2. **Một mục ở nhiều board:** bỏ ghim khỏi một board không làm nó mất khỏi board kia hay bị cắt. Test ở Task 1.
3. **Tên board trùng theo hoa thường và khoảng trắng:** " việc " và "Việc". Test ở Task 1.
4. **Bỏ ghim khi lịch sử đã đầy:** mục vừa bỏ ghim có thể bị cắt ngay nếu là mục cũ nhất. Test ở Task 1.
5. **Xoá board đang chứa mục:** mục vẫn còn trong lịch sử, số board giảm, không còn dòng mồ côi trong `board_items`. Test ở Task 1.

### Task 1: Board trong kho, lược đồ 4

**Files:** Create `Sources/ClipboardCore/ClipboardStore+Boards.swift`; Modify `ClipModels.swift`, `ClipboardStore.swift`; Test `Tests/ClipboardCoreTests/ClipboardStoreBoardTests.swift`; sửa các test phiên bản lược đồ hiện có để dùng `ClipboardStore.schemaVersion`

**Interfaces — Produces:**

```swift
public struct ClipBoard: Identifiable, Equatable, Sendable {
    public let id: Int64; public let name: String; public let symbolName: String; public let itemCount: Int
}
extension ClipboardStoreError { case invalidBoardName, duplicateBoardName, tooManyBoards, boardFull }
extension ClipboardStore {
    public static let schemaVersion = 4
    public static let maxBoards = 20, maxItemsPerBoard = 200, maxBoardNameLength = 40
    public func boards() throws -> [ClipBoard]
    @discardableResult public func createBoard(name: String, symbolName: String, at date: Date) throws -> ClipBoard
    public func updateBoard(id: Int64, name: String, symbolName: String) throws
    public func deleteBoard(id: Int64) throws
    public func pin(itemID: Int64, toBoard boardID: Int64, at date: Date) throws
    public func unpin(itemID: Int64, fromBoard boardID: Int64) throws
    public func items(inBoard boardID: Int64) throws -> [ClipItem]
    public func boardMembership() throws -> [Int64: Set<Int64>]
}
```
